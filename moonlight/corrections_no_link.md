Entry id is the entry's place in `corrections.json`, counting from 1. The file has no separate id field.

## What was searched

- Kashish's label-read sheets under `fixtures/labels_read/` (the README tables, and a saved label file when the table names a `.txt` instead of a URL). - Product's `task20_label_reads.csv` (9 rows), matched on the error id, the medicine's ChEMBL id and the disease id. None of those rows is one of these 142 entries.
- A match needs the medicine id and the disease id together. A label read for the same medicine on a different disease was not used.
