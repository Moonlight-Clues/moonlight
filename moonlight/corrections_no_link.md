## What was searched

- Kashish's label-read sheets under `fixtures/labels_read/` (the README tables, and a saved label file when the table names a `.txt` instead of a URL). The link is the first official regulator URL on that row: DailyMed `drugInfo`, FDA, EMA, PMDA, or medicines.org.uk. DailyMed's search address (`spls.json`) is not a label.
- Product's `task20_label_reads.csv` (9 rows), matched on the error id, the medicine's ChEMBL id and the disease id. None of those rows is one of these 142 entries.
- A match needs the medicine id and the disease id together. A label read for the same medicine on a different disease was not used.
